# Dolisoft Screen Management

Versions publiees du logiciel Dolisoft Screen Management (regie et affichage pour ecrans LED de stade).

Les postes equipes de la version 1.7.0 ou plus recente recoivent automatiquement les nouvelles versions publiees dans l'onglet Releases.
Chaque mise a jour est signee par Dolisoft : un fichier modifie ou non signe est refuse par le logiciel.
